
# VELOop Rewards – Task

A full-stack user profile and admin management application built using the MERN stack.

## Technology Stack
- React.js
- Vite
- Bootstrap
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure
- frontend/ – React user interface
- backend/ – Express API server

## Current Progress
- Initial React frontend setup
- User profile dashboard UI
- Express backend setup
- API health-check endpoint

## Development Status
Work in progress – approximately 20% completed.

## Local Development

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm run dev

## Security
Environment variables and credentials should be stored in local .env files and never committed to Git.
